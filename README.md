# PC_LED_HEADER-to-DESK_LED_STRIP
Here is the code and diagrams to make your own LED strip controller that egsepts the output from one of your motherboard LED headers to control 3rd party LED strips on your desk/room to match.
You will need agses to one of the following items to make it:
- arduino nano or uno (slower on reading WS2812B data)
- esp32 (will make code and diagram later when i get one)(best for the WS2812B LED strips and header output speeds)
You will need the following
- MOFITS IRLZ44N or simmular N-channel ones
- 220 ohm resistors
- 10k ohm resistors
- 12v powersorce (will make ways to use any powersorce your LED strip comes with in the future with more understanding)
- currently LED strips with contact points of 12V, R, G, & B (plan to make it compatible with any LED strip)

I do plan on making this a full open source thing, but I also plan one adding things like a custom pci board, 3d printed case, and more. 
  I will possibly sell premade things that are true plug and play.
This is currently just a personal project so I can just buy led strips and not need extra software to control them and so my desk lights 
  match my pc for a seemless look
